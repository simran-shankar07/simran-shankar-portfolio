# Simran Shankar — Portfolio Website

A responsive, static portfolio website ready for GitHub Pages. No build tools are required.

## Publish on GitHub Pages

1. Sign in to GitHub and click **New repository**.
2. Name the repository `simran-portfolio` (or choose your own name) and set visibility to **Public**.
3. Select **Add file → Upload files**. Upload `index.html`, `styles.css`, `script.js`, `work-links.json`, `.nojekyll`, and the entire `assets` folder. Commit the files.
4. In the repository go to **Settings → Pages**. Under **Build and deployment → Source**, select **Deploy from a branch**.
5. Choose branch **main**, folder **/(root)**, then **Save**.
6. Your site should become available at `https://YOUR-USERNAME.github.io/simran-portfolio/` (replace YOUR-USERNAME with the actual GitHub username and the repository name if different). GitHub will show the actual URL under Pages.

All paths are relative, so the website works both locally and from a GitHub Pages project repository.

## Edit the site

- Content: `index.html`
- Design: `styles.css`
- Work archive links: `work-links.json` (and the embedded `allWork` dataset at the beginning of `script.js`)
- Image assets and downloadable PDFs: `assets/`
